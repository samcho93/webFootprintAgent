KiCad Footprint Agent

로컬 브리지에 연결되지 않았습니다. KiCad 와 Claude CLI 는 내 PC 에서 실행되므로, 이 화면을 쓰기 전에 PC 에서 브리지를 켜 주세요. git clone https://github.com/samcho93/webFootprintAgent → 폴더에서 start.bat 실행 (또는 python run.py). 브라우저가 "로컬 네트워크의 기기에 접근" 권한을 물으면 허용하세요.

새 부품

PDF 를 끌어놓거나 클릭해서 선택

링크·파일이 없으면 에이전트가 웹에서 공식 데이터시트를 찾습니다.

폴더 일괄 생성

폴더의 PDF 마다 추출 → 생성 → 검증 → AI 검토 → 저장을 차례로 실행합니다. 파일 이름은 부품 번호 단서로만 쓰고, 실제 부품 · 패키지는 데이터시트 내용으로 판단합니다.

작업 기록

      라이브러리

        시작하기

        1. 부품 번호를 입력하거나 데이터시트 PDF/링크를 지정합니다.
        2. 에이전트가 데이터시트에서 핀 표와 패키지 도면을 읽어 사양을 추출합니다.
        3. 회로 기호(.kicad_sym)와 풋프린트(.kicad_mod)를 생성합니다.
        4. 규칙 검증 · KiCad CLI 파싱 · AI 교차 검토를 거쳐, 통과하면 라이브러리에 저장합니다.

        폴더 일괄 생성

        행을 누르면 그 부품의 결과(미리보기 · 검증 · AI 검토)가 아래에 열립니다.

        —

        .kicad_sym .kicad_mod

          사용법 
          
    
          1. 준비
          
    
            
      
          • Claude 연결 (둘 중 하나)
        
              
          
            • Claude Code CLI — API 키 없이 사용합니다. npm i -g @anthropic-ai/claude-code 설치 후 터미널에서 claude 를 한 번 실행해 로그인하면, 서버가 claude -p 를 헤드리스로 실행해 데이터시트 읽기(Read)·웹 검색(WebSearch/WebFetch)을 합니다. 상단 칩이 Claude CLI 연결 로 표시됩니다.
              • 
          
            • Anthropic API 키 — 프로젝트 폴더의 .env 에 ANTHROPIC_API_KEY=… 를 넣으면 API 로 직접 호출합니다 (키가 있으면 API 우선). FP_AGENT_BACKEND=cli 로 CLI 를 강제할 수 있습니다.
              • 
        
            • 
      
          • KiCad 9 — 설치되어 있으면 kicad-cli 를 자동으로 찾아 생성 파일이 실제로 KiCad 에서 열리는지 검증합니다. 경로가 다르면 KICAD_CLI 환경변수로 지정합니다.
            • 
    
          
    
          2. 부품 만들기 — 세 가지 입력 방법
          
    
          
      
          ① PDF 업로드
          데이터시트 PDF 를 끌어놓습니다. 가장 확실한 방법입니다.
          
      
          ② 데이터시트 링크
          PDF 주소(또는 PDF 링크가 있는 페이지)를 붙여넣으면 서버가 내려받습니다.
          
      
          ③ 부품 번호만
          링크·파일이 없으면 에이전트가 웹 검색으로 제조사 공식 데이터시트를 찾아 내려받습니다.
          
    
          
    
            
      
          • 패키지 지정 — 한 데이터시트에 여러 패키지(SOIC/TSSOP/QFN 등)가 있으면 원하는 것을 적어 주세요. 비우면 부품 번호의 주문 코드로 판단합니다.
            • 
      
          • AI 검토 — 끄면 추출 결과로 바로 생성·규칙 검증만 합니다 (빠르지만 교차 검토 없음).
            • 
      
          • 통과 시 자동 저장 — 규칙 검증 · KiCad 파싱 · AI 검토를 모두 통과하면 라이브러리에 바로 저장합니다.
            • 
    
          
    
          2-1. 폴더 일괄 생성
          
    
          데이터시트 PDF 가 모여 있는 폴더를 지정해 한 번에 만듭니다. 왼쪽 위 폴더 일괄 을 누르세요.
          
    
            
      
          1. 폴더 지정 — 경로를 붙여넣거나 찾아보기 로 내 PC 의 폴더를 고릅니다 (브리지가 이 PC 의 폴더 목록을 보여 줍니다). 필요하면 하위 폴더 포함.
            2. 
      
          2. PDF 찾기 — 폴더의 PDF 목록이 나옵니다. 이미 라이브러리에 저장된 데이터시트(파일 내용 SHA-1 이 같은 것)는 초록 표시와 함께 선택이 풀려 있습니다. 만들 파일만 체크합니다.
            3. 
      
          3. 옵션 — 라이브러리 이름, AI 검토, 통과 시 자동 저장, 이미 저장된 데이터시트 건너뛰기, 동시 처리(1~3개, Claude 사용량과 PC 성능에 맞춰 조절).
            4. 
      
          4. 일괄 생성 시작 — 오른쪽 진행 표에서 파일별 단계 · 결과(저장됨 / 검토 필요 / 실패 / 건너뜀)를 봅니다. 행을 누르면 그 부품의 미리보기 · 검증 · AI 검토가 아래에 열리고, 검토 필요 항목은 거기서 고쳐 저장합니다.
            5. 
      
          5. 중지 — 진행 중인 파일은 끝까지 처리하고 남은 파일은 건너뜁니다.
            6. 
    
          
    
          파일 이름은 부품 번호 단서로만 쓰고, 실제 부품 · 패키지는 데이터시트 내용으로 판단합니다. 한 데이터시트에 여러 부품 · 패키지가 있으면 대표 하나만 만들므로, 다른 변형은 단일 부품 모드에서 패키지 지정 으로 추가하세요.
          
    
          3. 결과 확인
          
    
          
      
          탭내용
          
      
          미리보기회로 기호와 풋프린트(패드 번호·1번 핀 표시·코트야드 포함). 체크박스로 KiCad CLI 렌더링과 비교할 수 있습니다.
          
      
          핀핀 번호 · 이름 · 전기적 타입 · 그룹
          
      
          패드패키지 치수 요약과 패드 좌표표 (원점 = 패키지 중심, Y 아래쪽 +, mm)
          
      
          검증규칙 검증 항목별 결과와 kicad-cli 로그
          
      
          AI 검토회차별 검토 판정, 지적 사항, 데이터시트 근거 페이지
          
      
          사양 편집추출된 사양 JSON 을 고쳐 즉시 재생성(AI 없이) 하거나 재생성 + AI 검토 를 다시 돌립니다.
          
    
          
    
          4. 저장과 KiCad 에서 사용
          
    
            
      
          • 상태가 검증 통과 이면 저장 버튼으로, 검토 필요 이면 내용을 확인한 뒤 강제 저장합니다.
            • 
      
          • 저장 위치: library/<라이브러리>.kicad_sym, library/<라이브러리>.pretty/*.kicad_mod, 근거 기록 library/specs/*.json, 데이터시트 사본 library/datasheets/.
            • 
      
          • KiCad → 환경설정 → 심볼/풋프린트 라이브러리 관리 에서 위 파일을 추가하거나, 함께 생성되는 sym-lib-table / fp-lib-table 항목을 복사해 사용합니다. 심볼의 Footprint 필드는 <라이브러리>:<풋프린트> 로 미리 연결되어 있습니다.
            • 
    
          
    
          5. Claude 없이 쓰기
          
    
          examples/ 폴더의 JSON 처럼 사양을 직접 작성해 사양 편집 탭에 붙여넣고 즉시 재생성 하면 생성 · 규칙 검증 · KiCad 검증까지 동작합니다.
          
    
          주의
          
    
          자동 생성 결과는 반드시 데이터시트와 대조해 확인한 뒤 실제 보드에 사용하세요. 특히 1번 핀 위치, 패드 번호 방향, 노출 패드(EP) 번호, 다이오드 극성은 검증 통과 후에도 눈으로 확인하는 것을 권장합니다.

          0.2.0 — Claude Code CLI 연동 (c72b6de)

          요청: API 키 없이 Claude CLI 로 webCadAgent 처럼 사용.
          

            

          • app/agents/claude_cli.py: 로그인된 claude CLI 를 헤드리스로 실행 (claude -p --output-format stream-json --json-schema …). PDF 는 임시 폴더에 두고 Read 도구로 읽기, 검색은 WebSearch · WebFetch, 결과는 structured_output.
            • 

          • 백엔드 자동 선택: ANTHROPIC_API_KEY 가 있으면 API, 없으면 CLI. FP_AGENT_BACKEND=api|cli 로 강제.
            • 

          • 서버가 시작할 때 프로젝트 .env 를 직접 읽음. 상단 칩에 「Claude CLI 연결」 표시.
            • 

          • CLI 탐색은 셸과 같은 PATH 순서 (~/.local/bin 의 오래된 2.1.63 대신 npm 의 2.1.287 사용).
            • 

          

          수정
          

            

          • 구조화 출력 스키마 버그: 스키마 변환이 title 키를 모두 지워 title 이라는 실제 필드까지 사라짐 → 데이터시트 검색이 실패. 속성 이름 맵은 건드리지 않도록 고침 (API 경로에도 같은 영향이 있었음).
            •
